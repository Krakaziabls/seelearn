## 🎯 Блок: Рассмотреть и учесть для UI/UX (Приоритетные замечания автора)

Данный блок сформирован на основе непосредственного опыта использования и критики текущего интерфейса. Задачи этого блока имеют высший приоритет для следующей итерации полировки.

- [x] **1. Таблицы в контенте карточки (`.seelearn-content table`)**
  - **Проблема:** В `.seelearn-content seelearn-back` таблицы рендерятся плоскими, без отступов, границ ячеек и заголовков. Выглядят как каша из текста, а не как нативные Markdown-таблицы Obsidian.
  - **Решение:** 
    - Добавить в `styles.css` полноценные стили нативных таблиц Obsidian: `border-collapse: collapse`, границы через `var(--table-border-color, var(--background-modifier-border))`, отступы `padding: 8px 12px` для `th` и `td`.
    - Стилизовать заголовок таблицы `th`: фон `var(--table-header-background, var(--background-secondary-alt))`, `font-weight: 600`, выравнивание.
    - Добавить чередующуюся подсветку строк `tr:nth-child(even)` (`var(--table-row-even-background)`).
    - Обеспечить корректный inline-рендеринг MathJax-контейнеров внутри ячеек без ломания вертикального выравнивания.

- [x] **2. Унификация стиля кнопки `[3] Хорошо` (`.seelearn-btn-good`)**
  - **Проблема:** Кнопка «Хорошо» имеет класс `mod-cta`, из-за чего выбивается из общего ряда 4-х кнопок оценок по высоте, обводке, цвету текста и заливке.
  - **Решение:**
    - Убрать класс `mod-cta` или жестко переопределить стили в `styles.css`, чтобы кнопка имела одинаковую структуру (рамка, прозрачный/полупрозрачный фон, акцентный цвет текста) и единообразный hover-эффект, как у кнопок «Снова», «Трудно» и «Легко».

- [x] **3. Горизонтальная модалка быстрого редактирования (Side-by-Side Edit Modal)**
  - **Проблема:** Текущая модалка вертикальная, поля ввода не зафиксированы по высоте (пользователь может случайно их растянуть), отсутствует контекст карточки (теги, путь, исходные маркеры).
  - **Решение:**
    - Сделать модальное окно широким (`max-width: 860px` / `width: 85vw`).
    - Использовать двухколоночный Side-by-Side лейаут: слева область **Лицевая сторона (Front)**, справа область **Оборотная сторона (Back)**.
    - Для карточек только с фронтом (Front-only info cards) выводить одну полноразмерную колонку редактирования фронта.
    - Зафиксировать высоту текстовых полей (`resize: none`, `height: 280px`, аккуратный скроллбар).
    - В шапке модалки отображать метаданные: файл, диапазон строк, список активных тегов карты.

- [x] **4. Компактный переключатель режима обучения (`.seelearn-mode-toggle`)**
  - **Проблема:** Сегментированная кнопка («📖 Ботать» / «🎯 Проверить знания») занимает слишком много места в шапке тулбара.
  - **Решение:**
    - Заменить на компактный аккуратный тогл/переключатель: тумблер с подписью **«Проверка знаний»** (или **«Тест»**).
    - Положение `OFF` — режим «Ботать» (чтение, без баллов).
    - Положение `ON` — режим проверки знаний (SRS, 4 кнопки, статистика).

- [x] **5. Удаление кнопки Undo из навбара**
  - **Проблема:** Кнопка «Отмена» (`.seelearn-btn-undo`) в панели навигации перегружает интерфейс и не несет практической ценности как постоянная видимая кнопка.
  - **Решение:**
    - Удалить кнопку из DOM навбара. Оставить функционал отмены исключительно по стандартному сочетанию клавиш `Ctrl+Z` / `Cmd+Z` для тех, кто случайно нажал не ту оценку, с выводом ненавязчивого Notice.

- [x] **6. Осмысленный менеджмент учебных сессий**
  - **Проблема:** Сессия сейчас стартует и заканчивается хаотично: непонятно, сколько всего карт запланировано, когда сессия началась, когда она считается завершенной, и как начать новую осознанно.
  - **Решение:**
    - **Экран входа в сессию (Lobby / Deck Overview):** перед началом показа карточек выводить экран готовности: количество созревших карт, новых карт, расчетное время сессии (~X мин), кнопка «Начать сессию».
    - **Четкий прогресс:** индикатор «Карта X из Y» в шапке, закрепленный объем сессии (не подмешивать на лету новые карты без ведома пользователя).
    - **Явный финиш сессии:** фиксация завершения с сохранением отметки времени в хранилище, итоговый отчет и предложение вернуться к выбору колод или пройти повтор ошибок.

- [x] **7. Замена всех эмодзи на иконки Material Design / Lucide Icons**
  - **Проблема:** Эмодзи (`📖`, `🎯`, `📁`, `📄`, `🔥`, `🏆`, `⚡`, `🎉`) на разных ОС (macOS / Windows / Linux / iOS / Android) отображаются в разном стиле, плывут по высоте строк и выглядят кустарно.
  - **Решение:**
    - Использовать встроенную в Obsidian API библиотеку иконок Lucide (`setIcon(el, 'icon-name')`) или SVG Material Icons.
    - Заменить:
      - Папки/файлы: `folder`, `file-text`.
      - Режимы: `book-open`, `crosshair` / `sparkles`.
      - Стрики и рекорды: `flame`, `trophy`, `layers`.
      - Пиявки/Ошибки: `alert-triangle`, `zap-off`.
      - Навигация: `chevron-left`, `chevron-right`.

- [x] **8. Фиксация поисковой строки тегов (`.seelearn-tag-search-box`)**
  - **Проблема:** Поле поиска тем уезжает за пределы экрана при горизонтальном скролле полосы тегов.
  - **Решение:**
    - Вынести `.seelearn-tag-search-box` из скролл-контейнера чипсов.
    - Сделать поисковый инпут липким (`position: sticky; left: 0; z-index: 2`) либо разместить его статично слева от скроллящегося блока тегов (`display: flex; flex-shrink: 0`).

- [x] **9. Навигационные стрелки по бокам карточки и прозрачный навбар**
  - **Проблема:** Кнопки «Назад» и «Далее» загромождают нижний навбар. Нижняя панель с фоновой заливкой утяжеляет интерфейс.
  - **Решение:**
    - Вынести кнопки перелистывания прямо в `.seelearn-card-area`: расположить крупные плавающие полупрозрачные стрелки (Lucide `chevron-left` и `chevron-right`) слева и справа от контейнера карточки, отцентрированные по вертикали.
    - В `.seelearn-nav-bar` убрать заливку (`background: transparent; border-top: none;`). Оставить там только кнопки оценок SRS (в режиме теста), прижатые к низу с максимальным «воздухом».

## 🚀 Бэклог основных фичей (Отсортирован по приоритету)

### Приоритет: Высокий (High Priority)

- [ ] **Свайп-навигация для мобильных устройств (Obsidian Mobile Touch Gestures)**
  - Добавить touch-обработчики (`touchstart`, `touchend`, `touchmove`) на контейнер карточки.
  - Свайп вверх: переворот карточки (Flip).
  - Свайп влево: следующая карта / «Снова» (Again).
  - Свайп вправо: предыдущая карта / «Хорошо» (Good).
  - Порог срабатывания свайпа (threshold ~60px) с защитой от случайных горизонтальных скроллов таблиц.

- [ ] **Множественные пропуски в одной карточке (Cloze $c1, c2, c3$)**
  - Разделять текст с несколькими разными маркерами (например, `{{c1::Киев}} — столица Украины, а {{c2::Варшава}} — Польши`) на $N$ независимых виртуальных карточек очереди.
  - На карточке $c1$ скрыт Киев, а Варшава видна как обычный текст. На карточке $c2$ — наоборот.

- [ ] **Кастомные горячие клавиши в настройках Obsidian (Hotkeys Integration)**
  - Зарегистрировать действия плагина через `this.addCommand()`:
    - `SeeLearn: Показать ответ / Перевернуть карточку`
    - `SeeLearn: Оценка «Снова» (Again)`
    - `SeeLearn: Оценка «Трудно» (Hard)`
    - `SeeLearn: Оценка «Хорошо» (Good)`
    - `SeeLearn: Оценка «Легко» (Easy)`
    - `SeeLearn: Следующая карточка`
    - `SeeLearn: Предыдущая карточка`
  - Позволить пользователям переназначать дефолтные `Space`, `1-4`, `Arrows` на любые комбинации в стандартном меню Hotkeys.

---

### Приоритет: Средний (Medium Priority)

- [ ] **Интеграция современного алгоритма FSRS (Free Spaced Repetition Scheduler v4/v5)**
  - Реализовать альтернативный движок планирования интервалов на базе FSRS (модель памяти DSR: Difficulty, Stability, Retrievability).
  - Добавить переключатель в настройках: `Алгоритм интервального повторения: SM-2 | FSRS`.
  - Обеспечить сохранение параметров стабильности ($S$) и сложности ($D$) в структуре `data.json`.

- [ ] **Мультиселект папок и гибкая фильтрация тегов (AND / OR Logic)**
  - Поддержка выбора нескольких папок для одной сессии (например, `Backend/Go` + `Backend/Databases`).
  - Переключатель логики фильтра тегов:
    - Режим **И (AND)**: карточка должна содержать все выбранные теги.
    - Режим **ИЛИ (OR)**: карточка содержит хотя бы один из выбранных тегов.

- [ ] **Детальный дашборд прогнозирования нагрузки (Retention Forecast & Analytics View)**
  - Отдельная вкладка или модальное окно с аналитикой:
    - График созревания карточек на 7, 30 и 90 дней вперед (Forecast).
    - Распределение карточек по фактору легкости ($EF$) и интервалам (короткие, средние, зрелые карты).
    - Процент удержания материала (True Retention Rate).

---

### Приоритет: Низкий (Low Priority / Nice-to-have)

- [ ] **Импорт / Экспорт колод (Anki `.apkg` / Markdown / CSV)**
  - Парсинг экспортированных колод Anki (`.txt`, `.csv` или распакованных `.apkg`) с автоматической генерацией Markdown-файлов с разметкой `%% @card %%`.
  - Экспорт накопленной истории прогресса и интервалов в CSV.

- [ ] **Звуковой и тактильный отклик (Sound Effects & Haptics)**
  - Опциональные негромкие звуковые эффекты щелчка при перевороте карточки и джингл при завершении очереди сессии.
  - Настройка громкости и возможность полного отключения.

## 📋 История уже реализованных релизов

- **v1.0.0 (MVP):** Парсер `%% @card %%` / `%% @front %%` / `%% @back %%` / `%% @end %%`, базовый View, фильтрация по тегам, прыжок к строке заметки.
- **v1.1.0 (Data Foundation):** Хэширование FNV-1a, дебаунсированное хранилище `data.json`, тасование Фишера-Йетса, чередование тем (Topic Interleaving).
- **v1.2.0 (Smart SRS Core):** Алгоритм SuperMemo-2 (Again, Hard, Good, Easy), очереди Due/New/All, прогноз интервалов на кнопках.
- **v1.3.0 (Visuals & Polish):** Разделение на «Ботать» и «Проверить знания», инфо-карточки без `@back`, фильтр по папкам, живой поиск тем $>6$, Undo (`Ctrl+Z`), дашборд сессии.
- **v1.4.0 (Performance & Architecture Polish):** Инкрементальная индексация (10 000+ заметок), Flush on Exit (защита от потери данных), миграция ID при переименовании файлов, поддержка Callouts (`> [!NOTE]`), мгновенный переворот (0ms) без перерендера DOM, изоляция фокуса хоткеев.
- **v1.5.0 (Cloze Deletions, Leeches & Study Analytics):** Карточки с пропусками (`{{c1::ответ}}` и `==выделение==`), детектор «Личей» (`⚡ ПИЯВКА`), быстрое редактирование (Edit in Place), 35-дневный Activity Heatmap, учет серий (`🔥 Стрик`).
- **v1.6.0 (UX Redesign & Session Flow):** Нативные Markdown-таблицы Obsidian с zebra striping и inline MathJax, унификация кнопки `[3] Хорошо`, Side-by-Side модалка быстрого редактирования (Front слева, Back справа, Ctrl+Enter), компактный переключатель режимов обучения, удаление кнопки Undo из DOM навбара (с сохранением хоткея Ctrl+Z), трехфазный жизненный цикл сессии (Lobby / Deck Overview -> Active Session с замороженной очередью -> Session Finish Dashboard), полная замена эмодзи на нативные иконки Lucide, липкий поиск тем, плавающие боковые стрелки навигации и прозрачный навбар.
