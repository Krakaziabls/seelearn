## [v1.8.0] — 2026-11-06

### 🚀 First-Run Experience (Онбординг) и Демо-активы
- **Автоматическая подготовка демонстрационной папки `SeeLearn Examples`**:
  - При первом запуске плагина в корне хранилища автоматически создается изолированная папка `SeeLearn Examples`.
  - Принцип **Zero Note Pollution**: плагин создает собственные автономные файлы и никогда не модифицирует существующие пользовательские заметки.
- **5 полноценных эталонных заметок с примерами**:
  1. `01 — Базовые двусторонние карточки.md`: классические двусторонние карточки (`@front` / `@back`), карточки с обратным порядком секций, скролл длинного контекста.
  2. `02 — Карточки с пропусками (Cloze Deletions).md`: синтаксис Anki `{{c1::ответ}}`, `{{c1::ответ::подсказка}}`, подсветка `==ответ==`, множественные пропуски $c1, c2$ и объединение пропусков с секцией `@back`.
  3. `03 — Карточки с кодом и программированием.md`: блоки кода с подсветкой синтаксиса (TypeScript, Python, Rust, SQL), экранирование символов и форматирование.
  4. `04 — Формулы LaTeX и точные науки.md`: формулы MathJax, inline-математика `$E=mc^2$`, многострочные выкладки `$$...$$`, дроби и матрицы.
  5. `05 — Конспект лекции со скрытыми картами.md`: интеграция карточек в реальный конспект лекции с полным скрытием в режиме чтения Obsidian (Reading View) через блоки `%%%% ... %%%%`.
- **Интерактивная заметка-справочник `Шпаргалка SeeLearn — Синтаксис и Методология.md`**:
  - Подробное руководство по синтаксису разметки, подключению заметок через теги и Frontmatter.
  - Разбор алгоритма интервального повторения SuperMemo-2 (SM-2), шкал оценок 1–4, очереди «К повторению» (Due) и поведения карточек-пиявок (Leeches).
  - Сгенерирована без активного управляющего тега `#seelearn`, чтобы не засорять очередь обучения самой справкой.
- **Постоянная кнопка справки `(?)` в навигационной панели**:
  - В левой группе панели навигации плагина добавлена кнопка `.seelearn-nav-help-btn` с иконкой `help-circle`.
  - Клик по кнопке фокусирует или открывает заметку-шпаргалку в новой вкладке редактора Obsidian, а в случае случайного удаления автоматически воссоздает её.
- **Удаление устаревших компонентов**:
  - Полностью удалено временное модальное окно `SRSMethodologyModal` и ссылка на него в лобби сессии.
- **Исправление Flexbox-схлопывания контента**:
  - Добавлены свойства `flex-shrink: 0; width: 100%` для контейнеров `.seelearn-content` и `.seelearn-answer-section`, исключающие сжатие вопроса при отображении широких блоков кода с горизонтальным скроллом.

## [v1.7.1] — 2026-10-26

### 📚 SRS Methodology, Presets & UI Polish
- **Сохранённые наборы тестов (Test Presets)**:
  - Возможность упаковать текущую выборку (папка, заметка, теги) в именованный тест («Сохранить как тест...»).
  - Быстрый запуск тестов в 1 клик прямо из Лобби проверки знаний.
  - Учет запусков тестов (`runsCount`, `lastRun`) и персональное поздравление на экране итогов.
- **Строгая двухсторонняя структура карт & упрощенный Cloze**:
  - Карточки без оборотной стороны (`@front` без `@back`) больше не разрешены для обычных карт.
  - Для карт с пропусками (Cloze) маркеры `@front` и `@back` теперь опциональны: достаточно написать `%% @card %%\nТекст {{c1::пропуск}}\n%% @end %%`.
- **Полное скрытие карточек через многострочные комментарии `%%%% ... %%%%`**:
  - Возможность оборачивать карточки в конспектах блоками `%%%% ... %%%%` (или `%% ... %%`), чтобы они были полностью невидимы в режиме чтения Obsidian (Reading View).
- **Быстрая вставка шаблонов по хоткеям**:
  - Команды `SeeLearn: Вставить шаблон карточки` и `SeeLearn: Вставить шаблон карточки с пропуском`.
  - Выбор стиля шаблона в параметрах: в комментариях (`%% ... %%`) или открытым текстом (`@card ... @end`).
- **Перемешивание очереди на лету во время сессии**:
  - Тасование оставшейся части колоды без сброса уже пройденных карточек.
- **Редизайн карточек-пиявок**:
  - Исправлена ошибка с ложным бейджем «Новая карта» у забытой пиявки с `repetitions = 0`.
  - Спокойный янтарный оттенок бейджа и нативная иконка `alert-circle`.
- **Минималистичный значок для Cloze-карт**:
  - Компактный значок ножниц взамен громоздкого бейджа `КЛОУЗ`.
- **Фиксированная ширина кнопок переключения режима**:
  - Одинаковая ширина кнопки режима (170px) исключает горизонтальный сдвиг тулбара.
- **Скролл длинного контекста**:
  - Ограничение карточки по высоте и плавный вертикальный скролл тела карточки.

## [v1.7.0] — 2026-10-24

### 📱 Mobile Swipes & Multi-Cloze
- **Свайп-навигация для мобильных устройств (Obsidian Mobile Touch Gestures)**:
  - Свайп вверх: переворот карточки (показать ответ).
  - Свайп влево: следующая карточка / оценка «Снова» (Again).
  - Свайп вправо: предыдущая карточка / оценка «Хорошо» (Good).
  - Исключение ложных срабатываний при горизонтальном скролле таблиц и кода.
- **Множественные пропуски в одной карточке (Multi-Cloze $c1, c2$)**:
  - Карточки с несколькими маркерами автоматически разделяются на $N$ независимых виртуальных карточек с отдельным прогрессом SM-2.
- **Интеграция с горячими клавишами Obsidian**:
  - Регистрация всех ключевых действий плагина в командную палитру и настройки хоткеев Obsidian.
