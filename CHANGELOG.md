## [v1.11.0] — 2026-11-07

### 📐 Гибкая система размеров карточек (Card Sizing & Presets)
- **Дискретная шкала размеров**:
  - 6 фиксированных пресетов: `xs` (480×340px), `s` (560×400px), `m` (640×460px, стандарт по умолчанию, гармонирует с лобби), `l` (800×560px), `xl` (960×660px) и `full` (во весь экран рабочей области).
- **4-уровневая иерархия разрешения размера**:
  1. Явный размер в разметке карточки: `@size:xs`, `@size:s`, `@size:m`, `@size:l`, `@size:xl`, `@size:full` (наивысший приоритет).
  2. Размер заметки из свойств YAML frontmatter (по умолчанию `card_size: l`, имя свойства настраивается в параметрах).
  3. Сохраненный в сессии интерактивный размер карточки в `data.json` (действует только для карт без `@size:` и свойства в файле).
  4. Глобальный размер по умолчанию из настроек плагина (`defaultCardSize`, по умолчанию `m`).
- **Интерактивное масштабирование карточки**:
  - Кнопка разворачивания во весь экран (`maximize-2` / `minimize-2`) в шапке карточки с запоминанием и восстановлением предыдущего размера.
  - Угловой хэндл в правом нижнем углу карточки (`seelearn-card-resize-handle`) для плавного ресайза мышью или тачем с автоматическим снапом к ближайшему пресету.
- **Персистентность без загрязнения заметок (Zero Note Pollution)**:
  - Размеры, измененные пользователем в сессии для карт без явного размера, сохраняются в `data.json` и восстанавливаются во всех последующих сессиях.
  - В настройках плагина добавлена кнопка «Сбросить сохранённые размеры карточек» для моментального возврата всех кастомных карт к текущему дефолту.
- **Геометрическая безопасность навигации**:
  - Боковые стрелки навигации (`prev` и `next`) изолированы от изменений размера карточки и сохраняют зазор $\ge 20\text{px}$, исключая перекрытия даже в полноэкранном режиме.

### ⚡ Быстрые нативные тултипы и полировка шапки карточки
- **Лаконичная шапка карточки**:
  - Удалена избыточная плашка `.seelearn-file-link`.
  - Кнопка перехода к заметке (`seelearn-jump-btn`) снабжена нативным быстрым тултипом Obsidian с именем файла и номером строки (`filename:line`).
- **Устранение двойных тултипов**:
  - По всему плагину устранен конфликт Chromium-атрибута `title` с быстрым тултипом Obsidian (`setTooltip`), исключая повторное появление белой системной подсказки поверх интерфейса.
- **Устранение бага с «зависшим» тултипом**:
  - Реализован жизненный цикл `clearActiveTooltips()`: при смене карточки, завершении сессии или расфокусировке окна все активные тултипы корректно очищаются, а элементам посылается `mouseleave`, гарантируя отсутствие осиротевших плавающих плашек на экране.

## [v1.10.0] — 2026-11-07

### 🎯 Управление сессией, гибкие лимиты и контекстное лобби
- **Интерактивный счетчик карточек и выбор лимита (`Кол-во карт: N ▾`)**:
  - Центральный счетчик карточек стал интерактивным меню для настройки размера учебной сессии.
  - Динамическая фильтрация пресетов (10, 20, 50, 100): варианты, превышающие размер доступного пула карт, автоматически скрываются.
  - Возможность указать произвольный лимит через модальное окно `CustomLimitModal` и зафиксировать дефолтное значение в настройках плагина.
- **Честное равномерное сэмплирование карточек (`prepareSessionPool`)**:
  - При установке лимита пул карточек перемешивается алгоритмом Фишера-Йетса перед выборкой, гарантируя репрезентативное случайное распределение карточек без перекосов.
  - Поддержка линейного порядка карточек (`linearSessionOrder`) как альтернативного режима.
- **Ранний выход из активной сессии с сохранением прогресса**:
  - В навигационной панели добавлена кнопка выхода (`.seelearn-nav-exit-btn` с иконкой `log-out`) для обоих режимов («Ботать» и «Проверка знаний»).
  - При досрочном выходе наработанный прогресс по всем оцененным карточкам немедленно сохраняется на диск (`saveNow()`), и открывается экран с персональной статистикой сессии.
- **Завершение сессии в режиме «Ботать» на последней карточке**:
  - После просмотра оборотной стороны последней карточки нажатие Пробела (`Space`) или правой стрелки (`seelearn-side-arrow next` / `ArrowRight`) переводит сессию на экран «Сессия завершена».
  - Кнопка в панели навигации и подсказка на карточке динамически обновляются на `«Завершить сессию (Space)»`.
- **Контекстная сетка карточек статистики в лобби**:
  - В лобби отображаются ровно 2 карточки вместо 4, адаптируясь под выбранную очередь:
    - При фильтре `«Все»`: карточка `Пул карт` + `Расчетное время`.
    - При фильтре `«К повторению»`: карточка `К повторению` (оранжевый цвет `.text-warning`) + `Расчетное время`.
    - При фильтре `«Новые»`: карточка `Новые` (синий цвет `.text-new`, синхронный с фоном кнопки) + `Расчетное время`.
  - Пресеты тестов автоматически скрываются при фильтрации по `due` или `new`.
- **Полировка визуала и типографики**:
  - Иконки в `.seelearn-streak-pill` идеально выровнены по тексту по центру через `inline-flex`.
  - Грамматически точная формулировка флипов: `«Всего: N флипа / флипов»` с учетом русской плюрализации.
  - Лаконичный тулбар и панель тем: автоскрытие тегов во время сессии без лишних кнопок.

## [v1.9.0] — 2026-11-06

### ✨ Редизайн интерфейса, фокусировка сессии и сворачивание тем
- **Сворачиваемая панель тем (`.seelearn-tags-bar`)**:
  - Возможность свернуть блок тегов прямо в лобби одним кликом по кнопке со стрелкой (`chevron-up`).
  - В тулбар добавлена кнопка-переключатель тем (`tags`) с индикацией активного состояния и точкой-бейджем, если теги отфильтрованы.
  - Ширина поисковой строки тегов строго синхронизирована с переключателем режимов (`170px` через единую CSS-переменную `--seelearn-toggle-width`).
  - **MRU-очередь выбранных тегов**: свежевыбранные темы мгновенно выстраиваются в начало списка слева (рядом с «Все темы»), а при снятии выбора возвращаются на свое естественное место.
- **Фокусировка активной сессии (Smart Session Focus)**:
  - Во время прохождения карточек (`active`) панель тегов и пилюли фильтрации SRS (`.seelearn-srs-filter-group`) автоматически скрываются, освобождая экран от отвлекающих элементов.
  - При возвращении в лобби фильтры и темы мгновенно восстанавливаются.
- **Единый лейаут действий в нижней панели (`.seelearn-nav-bar`)**:
  - Кнопки перемешивания («Перемешать колоду» / `shuffle`) и переиндексации (`refresh-cw`) перенесены из верхнего тулбара вниз и объединены с кнопкой справки (`help-circle`) в группу `.seelearn-nav-actions`.
  - Все иконочные кнопки стандартизированы под размер `28×28px` с зазором `6px` и нативными состояниями наведения Obsidian.
  - Сохранена строгая симметрия боковых блоков (`flex: 1 1 0`), гарантирующая истинное центрирование кнопок ответа (`[Space]`) и шкал SM-2 (`[1]–[4]`).
- **Строгое центрирование счетчика карточек**:
  - Счетчик карточек (`.seelearn-counter-badge`) зафиксирован абсолютно по центру тулбара и не сдвигается при изменении соседей.
  - Формат текста стандартизирован: `В очереди: N` и `Карта X из Y` (убран устаревший суффикс `карт`).
- **Стабилизация размеров пилюль очередей SRS**:
  - Зафиксированы постоянная высота (`26px`), паддинги и одинаковый вес шрифта (`font-weight: 500`) во всех состояниях (активном и неактивном), устраняя скачки вёрстки при переключении очередей.
- **Модальное окно сохранения тестов (`SaveTestModal`)**:
  - Окно центрировано по экрану, расширено до `min(640px, 90vw)`, а кнопки «Отмена» и «Сохранить тест» выровнены по правому краю с увеличенным интервалом `14px`.
- **Очистка карточки и Zero Note Pollution**:
  - Полностью удалена кнопка быстрого инлайн-редактирования из шапки карточки (редактирование происходит в исходных заметках по клику на заметку).
  - Кнопка перехода к заметке перенесена вправо и стала строго иконочной (`26×26px`).
  - Ссылка на заметку и контейнер тегов сбалансированы ровно 50/50 с горизонтальным скроллом для длинных имен.
  - Удален избыточный бейдж cloze-прогресса в шапке карточки.
  - Унифицированы кнопки на экране итогов (`38px`, одинаковые радиусы и равная ширина).

## [v1.8.0] — 2026-11-06

### 🚀 First-Run Experience (Онбординг) и Демо-активы
- **Автоматическая подготовка демонстрационной папки `SeeLearn Examples`**:
  - При первом запуске плагина в корне хранилища автоматически создается изолированная папка `SeeLearn Examples`.
  - Принцип **Zero Note Pollution**: плагин создает собственные автономные файлы и никогда не модифицирует существующие пользовательские заметки.
- **5 полноценных эталонных заметок с примерами**:
  1. `01 — Базовые двусторонние карточки.md`: классические двусторонние карточки (`@front` / `@back`), карточки с обратным порядком секций, скролл длинного контекста.
  2. `02 — Карточки с пропусками (Cloze Deletions).md`: синтаксис Anki `{{c1::ответ}}`, `{{c1::ответ::подсказка}}`, подсветка `==ответ==`, множественные пропуски $c1, c2$ и объединение пропусков с секцией `@back`.
  3. `03 — Карточки с кодом и программированием.md`: блоки кода с подсветкой синтаксиса (TypeScript, Python, Rust, SQL), экранирование символов и форматирование.
  4. `04 — Формулы LaTeX и точные науки.md`: формулы MathJax, inline-математика `$E=mc^2$`, многострочные выкладки `$$...$$`, дроби и матрицы.
  5. `05 — Конспект лекции со скрытыми картами.md`: интеграция карточек в реальный конспект лекции с полным скрытием в режиме чтения Obsidian (Reading View) через блоки `%%%% ... %%%%`.
- **Интерактивная заметка-справочник `Шпаргалка SeeLearn — Синтаксис и Методология.md`**:
  - Подробное руководство по синтаксису разметки, подключению заметок через теги и Frontmatter.
  - Разбор алгоритма интервального повторения SuperMemo-2 (SM-2), шкал оценок 1–4, очереди «К повторению» (Due) и поведения карточек-пиявок (Leeches).
  - Сгенерирована без активного управляющего тега `#seelearn`, чтобы не засорять очередь обучения самой справкой.
- **Постоянная кнопка справки `(?)` в навигационной панели**:
  - В левой группе панели навигации плагина добавлена кнопка `.seelearn-nav-help-btn` с иконкой `help-circle`.
  - Клик по кнопке фокусирует или открывает заметку-шпаргалку в новой вкладке редактора Obsidian, а в случае случайного удаления автоматически воссоздает её.
- **Удаление устаревших компонентов**:
  - Полностью удалено временное модальное окно `SRSMethodologyModal` и ссылка на него в лобби сессии.
- **Исправление Flexbox-схлопывания контента**:
  - Добавлены свойства `flex-shrink: 0; width: 100%` для контейнеров `.seelearn-content` и `.seelearn-answer-section`, исключающие сжатие вопроса при отображении широких блоков кода с горизонтальным скроллом.

## [v1.7.1] — 2026-10-26

### 📚 SRS Methodology, Presets & UI Polish
- **Сохранённые наборы тестов (Test Presets)**:
  - Возможность упаковать текущую выборку (папка, заметка, теги) в именованный тест («Сохранить как тест...»).
  - Быстрый запуск тестов в 1 клик прямо из Лобби проверки знаний.
  - Учет запусков тестов (`runsCount`, `lastRun`) и персональное поздравление на экране итогов.
- **Строгая двухсторонняя структура карт & упрощенный Cloze**:
  - Карточки без оборотной стороны (`@front` без `@back`) больше не разрешены для обычных карт.
  - Для карт с пропусками (Cloze) маркеры `@front` и `@back` теперь опциональны: достаточно написать `%% @card %%\nТекст {{c1::пропуск}}\n%% @end %%`.
- **Полное скрытие карточек через многострочные комментарии `%%%% ... %%%%`**:
  - Возможность оборачивать карточки в конспектах блоками `%%%% ... %%%%` (или `%% ... %%`), чтобы они были полностью невидимы в режиме чтения Obsidian (Reading View).
- **Быстрая вставка шаблонов по хоткеям**:
  - Команды `SeeLearn: Вставить шаблон карточки` и `SeeLearn: Вставить шаблон карточки с пропуском`.
  - Выбор стиля шаблона в параметрах: в комментариях (`%% ... %%`) или открытым текстом (`@card ... @end`).
- **Перемешивание очереди на лету во время сессии**:
  - Тасование оставшейся части колоды без сброса уже пройденных карточек.
- **Редизайн карточек-пиявок**:
  - Исправлена ошибка с ложным бейджем «Новая карта» у забытой пиявки с `repetitions = 0`.
  - Спокойный янтарный оттенок бейджа и нативная иконка `alert-circle`.
- **Минималистичный значок для Cloze-карт**:
  - Компактный значок ножниц взамен громоздкого бейджа `КЛОУЗ`.
- **Фиксированная ширина кнопок переключения режима**:
  - Одинаковая ширина кнопки режима (170px) исключает горизонтальный сдвиг тулбара.
- **Скролл длинного контекста**:
  - Ограничение карточки по высоте и плавный вертикальный скролл тела карточки.
