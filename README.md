# SeeLearn — Плагин интерактивных флеш-карт для Obsidian

**SeeLearn** — это плагин для [Obsidian](https://obsidian.md), который превращает размеченные фрагменты в ваших Markdown-заметках в интерактивные карточки для изучения и повторения материала.

Плагин поддерживает **полноценный нативный рендеринг Obsidian**: формулы LaTeX, подсветку синтаксиса кода, таблицы, списки задач, Callouts, изображения `![[...]]` и внутренние ссылки `[[...]]`.

    - `SeeLearn: Вставить шаблон карточки (Insert Card Template)`

## Что нового в v1.7.0 (Mobile & Multi-Cloze)

- 📱 **Полноценная свайп-навигация для мобильных устройств (Obsidian Mobile Touch Gestures)**:
  - Нативные touch-жесты для быстрого повторения карточек на смартфонах и планшетах:
    - **Свайп вверх**: переворот карточки (показать ответ).
    - **Свайп влево**: следующая карточка / оценка «Снова» (Again) при показанном ответе в режиме теста.
    - **Свайп вправо**: предыдущая карточка / оценка «Хорошо» (Good) при показанном ответе в режиме теста.
  - Порог смещения (~55px) и фильтрация длительности исключают ложные срабатывания при тапах.
  - Безопасный режим `touch-action: pan-y` и автоматическое определение горизонтально прокручиваемых элементов (`table`, `pre`, полоса тегов): горизонтальный скролл таблиц с кодом не вызывает случайный свайп карты.
- 🧩 **Множественные пропуски в одной карточке (Multi-Cloze Deletions $c1, c2, c3$)**:
  - Карточки с несколькими отдельными маркерами (например, `{{c1::Киев}} — столица Украины, а {{c2::Варшава}} — Польши`) автоматически разделяются на $N$ независимых виртуальных карточек в очереди повторения.
  - На карточке $c1$ скрыт первый факт, а второй отображается обычным читаемым текстом. На карточке $c2$ — наоборот.
  - Каждая cloze-карточка имеет собственный независимый прогресс интервального повторения SM-2 и бейдж в шапке: `КЛОУЗ (c1)`, `КЛОУЗ (c2)` с соответствующим локальным тегом `#c1`, `#c2`.
- ⌨️ **Интеграция с меню горячих клавиш Obsidian (Obsidian Hotkeys Integration)**:
  - Все ключевые действия зарегистрированы через `addCommand` в командную палитру Obsidian:
    - `SeeLearn: Показать ответ / Перевернуть карточку (Flip Card)`
    - `SeeLearn: Следующая карточка (Next Card)`
    - `SeeLearn: Предыдущая карточка (Previous Card)`
    - `SeeLearn: Оценка SRS: [1] Снова (Again)`
    - `SeeLearn: Оценка SRS: [2] Трудно (Hard)`
    - `SeeLearn: Оценка SRS: [3] Хорошо (Good)`
    - `SeeLearn: Оценка SRS: [4] Легко (Easy)`
    - `SeeLearn: Отменить последнее действие (Undo)`
  - Пользователи могут назначить любые удобные хоткеи (Vim-навигация, цифровая клавиатура, боковые кнопки) в стандартных настройках Obsidian (*Settings -> Hotkeys*).

  - На дашборде завершения сессии отображается тепловая карта активности за последние 5 недель с градиентной подсветкой интенсивности и всплывающими подсказками.

## Основные возможности

- 🧠 **Умное интервальное повторение (SuperMemo-2 / SM-2)**:
  - 4 градации оценки при ответе: **[1] Снова** (`<1д`), **[2] Трудно**, **[3] Хорошо**, **[4] Леко**.
  - Динамический расчет интервала и фактора легкости ($EF \ge 1.3$).
  - Живой прогноз следующего интервала прямо на кнопках до клика.
- 🎯 **Очереди обучения (Due / New / All)**:
  - Вкладки в тулбаре для выбора: **«Все»**, **«К повторению»** (созревшие на сегодня по графику SM-2), **«Новые»** (еще не изученные).
  - Настройка лимитов новых и созревших карт за сессию в параметрах.
- 🔄 **Два переключаемых режима**:
  - **«📖 Ботать»**: чтение и повторение материала в своем темпе.
  - **«🎯 Проверить знания»**: интервальное тестирование SM-2.
- 🔍 **Автоматическая индексация по Frontmatter**: плагин сканирует только те заметки, в свойствах которых указан управляющий тег (по умолчанию `#seelearn` в свойстве `tags`).
- 🔑 **Детерминированное хэширование карточек (FNV-1a)**: ID карточки генерируется на основе нормализованного содержимого и не сбрасывается при редактировании заметок или смещении строк. Также поддерживается явный ID: `%% @card id::custom-id %%`.
- 💾 **Хранение прогресса без изменения заметок**: весь прогресс, счетчики повторений, интервалы и забывания сохраняются в `data.json` плагина с дебаунсированной записью.
- 🔀 **Честный алгоритм тасования (Фишер-Йетс) и чередование тем (Interleaving)**: умное перемешивание распределяет карточки разных тем по очереди, предотвращая скопление однотипных карточек подряд.
- 🏷️ **Наследование атрибутов (тем/тегов)**:
  - **Глобальные темы**: берутся из свойства файла в Frontmatter (например, `topics: [JavaScript, Web]`).
  - **Локальные теги**: указываются прямо в карточке (например, `%% @card #async #сложно topic:: Frontend %%`).
  - Все атрибуты объединяются в единый набор без дубликатов.
- 🎨 **Нативный рендеринг Obsidian API**: отрисовка через `MarkdownRenderer.render` с корректной выгрузкой компонентов и защитой от утечек памяти.
- 🧭 **Интерактивный интерфейс изучения (Study View)**:
  - Индикатор статуса карточки (`ИНФО`, `КАРТОЧКА`, `Новая карта` / `Интервал: X дн.`).
  - Фильтрация по файлам, папкам и кликабельным тегам-чипсам с живым поиском.
  - Кнопка перемешивания колоды (Shuffle).
  - Быстрый переход к исходнику в заметке с позиционированием курсора на нужной строке.
  - Два режима показа ответа: отображение ответа под вопросом через разделитель либо замена вопроса ответом при перевороте.
- ⌨️ **Горячие клавиши**:
  - `Space` — показать ответ / перейти к следующей карте.
  - `1`, `2`, `3`, `4` — выбор оценки (Снова, Трудно, Хорошо, Легко) в режиме «Проверить знания».
  - `ArrowLeft` / `ArrowRight` — навигация по карточкам.
  - `Ctrl+Z` / `Cmd+Z` — отмена последнего действия.

## Синтаксис разметки

### 1. Подготовка заметки (Frontmatter)

Чтобы файл обрабатывался плагином, добавьте управляющий тег в свойства:

```yaml
---
tags:
  - seelearn
topics:
  - Компьютерные сети
---
```

### 2. Разметка карточки

#### Двусторонняя карточка (вопрос и ответ):
```markdown
%% @card #tcp #handshake %%
%% @front %%
Как происходит трехстороннее рукопожатие (Three-way handshake) в TCP?
%% @back %%
1. Клиент отправляет **SYN** (Synchronize).
2. Сервер отвечает **SYN-ACK**.
3. Клиент отправляет **ACK** (Acknowledge).

После этого соединение считается установленным.
%% @end %%
```

#### Карточка с заполнением пропусков (Cloze Deletions):
Для клоуз-карт маркеры `@front` и `@back` указывать **не обязательно**:
```markdown
%% @card #история %%
Столица Франции — {{c1::Париж::город}}, а основана она была в {{c2::III веке до н. э.}}.
%% @end %%
```

#### Полное скрытие карточек в конспекте (`%%%%`):
Чтобы карточка была абсолютно невидимой в режиме чтения Obsidian (Reading View) и не отвлекала при чтении конспекта:
```markdown
%%%%
@card #биология
@front
Что является «энергетической станцией» клетки?
@back
Митохондрии.
@end
%%%%
```

#### Альтернативный открытый синтаксис (без `%%`):
```markdown
@card #алгоритмы #сложность
@front
Какова средняя временная сложность быстрой сортировки (QuickSort)?
@back
Средняя сложность: $O(n \log n)$
Худшая сложность: $O(n^2)$
@end
```

### 3. Правила валидации:
- Двусторонняя карточка строго требует оба блока: и `@front`, и `@back`. Карточки с одним только `@front` без `@back` считаются невалидными.
- Исключение: карточки с клоуз-пропусками (`{{c1::...}}` или `==...==`), которые генерируют оборотную сторону автоматически и могут вообще не содержать маркеров `@front` и `@back`.
- Порядок блоков `@front` и `@back` внутри карточки может быть любым. При изучении всегда первым показывается `@front`.
- Если обязательные блоки отсутствуют или дублируются, плагин выводит предупреждение и пропускает невалидную карточку.

## Установка и сборка

1. Установите зависимости:
```bash
npm install
```

2. Запуск тестов:
```bash
npm test
```

3. Сборка для публикации:
```bash
npm run build
```

Файлы `main.js`, `manifest.json` и `styles.css` помещаются в папку плагина в вашем хранилище:
`<Vault>/.obsidian/plugins/seelearn/`
