# SeeLearn — Плагин интерактивных флеш-карт для Obsidian

**SeeLearn** — это плагин для [Obsidian](https://obsidian.md), который превращает размеченные фрагменты в ваших Markdown-заметках в интерактивные карточки для изучения и повторения материала.

Плагин поддерживает **полноценный нативный рендеринг Obsidian**: формулы LaTeX, подсветку синтаксиса кода, таблицы, списки задач, Callouts, изображения `![[...]]` и внутренние ссылки `[[...]]`.

## Что нового в v1.6.0 (UX Redesign & Session Flow)

- 📊 **Нативный рендеринг Markdown-таблиц Obsidian**:
  - Таблицы в теле карточки рендерятся с полноценными границами, отступами ячеек, стилизованной шапкой, зебра-подсветкой строк `tr:nth-child(even)` и идеальным выравниванием inline-формул MathJax.
- 🎯 **Унификация кнопки `[3] Хорошо`**:
  - Устранен конфликт со стилями `mod-cta`: кнопка теперь оформлена единообразно с кнопками «Снова», «Трудно» и «Легко».
- 🖥️ **Горизонтальная Side-by-Side модалка быстрого редактирования**:
  - Двухколоночный лейаут: слева Лицевая сторона (@front), справа Оборотная сторона (@back).
  - Зафиксированная высота текстовых полей (`resize: none`), исключающая случайное растягивание.
  - Метаданные в шапке модалки: путь к файлу, диапазон строк, теги карточки.
  - Быстрое сохранение по `Ctrl+Enter` / `Cmd+Enter`.
- 🎛️ **Компактный переключатель режима обучения**:
  - Компактный тумблер с нативной иконкой Lucide взамен широкой сегментированной кнопки.
- 🧹 **Очистка навбара от кнопки Undo**:
  - Кнопка отмены удалена из DOM навбара для разгрузки интерфейса; отмена работает по `Ctrl+Z` / `Cmd+Z` с показом Notice.
- 🚀 **Осмысленный трехфазный менеджмент сессий**:
  - **Lobby / Deck Overview**: экран готовности с подсчетом созревших и новых карт, расчетным временем сессии и кнопкой старта (или по клавишам `Space` / `Enter`).
  - **Замороженная очередь**: объем сессии строго зафиксирован при старте.
  - **Экран финиша**: итоговый отчет сессии с возможностью вернуться в лобби или запустить повтор ошибок.
- 🎨 **Полный отказ от эмодзи в пользу нативных Lucide Icons**:
  - Замена всех платформозависимых эмодзи на встроенные иконки Obsidian (`folder`, `file-text`, `crosshair`, `book-open`, `zap`, `scissors`, `flame`, `trophy`, `layers`).
- 📌 **Липкая строка поиска тем (`.seelearn-tag-search-box`)**:
  - Поисковое поле тем зафиксировано слева и больше не уезжает при горизонтальной прокрутке тегов.
- ↔️ **Плавающие боковые стрелки навигации и прозрачный навбар**:
  - Стрелки перелистывания (`chevron-left` и `chevron-right`) вынесены по бокам контейнера карточки.
  - Нижний навбар стал полностью прозрачным без разделительной полосы.

## Что нового в v1.5.0 (Cloze Deletions, Leeches & Study Analytics)

- 🧩 **Поддержка карточек с пропусками (Cloze Deletions)**:
  - Поддержка синтаксиса Anki: `{{c1::ответ}}`, `{{c1::ответ::подсказка}}`, `{{ответ}}`.
  - Поддержка нативного выделения Obsidian: `==ответ==`.
  - Автоматическое создание двухсторонней карточки без необходимости писать `@back`: на лицевой стороне отображается `[...]` или `[подсказка]`, а на обороте — подсвеченный правильный ответ!
- ⚡ **Детектор проблемных карточек («Пиявки» / Leech Detection)**:
  - Карточки, на которых вы нажимали «Снова» $\ge N$ раз (по умолчанию: 4, настраивается в параметрах), автоматически помечаются бейджем `⚡ ПИЯВКА`.
  - На сводном дашборде выводится предупреждение с кнопкой мгновенного запуска отдельной сессии по проблемным карточкам.
- ✏️ **Быстрое редактирование карточки (Edit in Place)**:
  - Кнопка **«Изменить»** в шапке карточки открывает модальное окно прямого редактирования `@front` и `@back` без необходимости уходить из режима повторения в файл заметки.
- 📅 **Интерактивный календарь активности (35-Day Activity Heatmap)**:
  - На дашборде завершения сессии отображается тепловая карта активности за последние 5 недель с градиентной подсветкой интенсивности и всплывающими подсказками.
- 🔥 **Трекинг серий обучения (Study Streaks)**:
  - Подсчет текущей непрерывной серии дней подряд (`🔥 Стрик`), личного рекорда (`🏆 Рекорд`) и общего числа пройденных карточек.

## Основные возможности

- 🧠 **Умное интервальное повторение (SuperMemo-2 / SM-2)**:
  - 4 градации оценки при ответе: **[1] Снова** (`<1д`), **[2] Трудно**, **[3] Хорошо**, **[4] Леко**.
  - Динамический расчет интервала и фактора легкости ($EF \ge 1.3$).
  - Живой прогноз следующего интервала прямо на кнопках до клика.
- 🎯 **Очереди обучения (Due / New / All)**:
  - Вкладки в тулбаре для выбора: **«Все»**, **«К повторению»** (созревшие на сегодня по графику SM-2), **«Новые»** (еще не изученные).
  - Настройка лимитов новых и созревших карт за сессию в параметрах.
- 🔄 **Два переключаемых режима**:
  - **«📖 Ботать»**: чтение и повторение материала в своем темпе.
  - **«🎯 Проверить знания»**: интервальное тестирование SM-2.
- 🔍 **Автоматическая индексация по Frontmatter**: плагин сканирует только те заметки, в свойствах которых указан управляющий тег (по умолчанию `#seelearn` в свойстве `tags`).
- 🔑 **Детерминированное хэширование карточек (FNV-1a)**: ID карточки генерируется на основе нормализованного содержимого и не сбрасывается при редактировании заметок или смещении строк. Также поддерживается явный ID: `%% @card id::custom-id %%`.
- 💾 **Хранение прогресса без изменения заметок**: весь прогресс, счетчики повторений, интервалы и забывания сохраняются в `data.json` плагина с дебаунсированной записью.
- 🔀 **Честный алгоритм тасования (Фишер-Йетс) и чередование тем (Interleaving)**: умное перемешивание распределяет карточки разных тем по очереди, предотвращая скопление однотипных карточек подряд.
- 🏷️ **Наследование атрибутов (тем/тегов)**:
  - **Глобальные темы**: берутся из свойства файла в Frontmatter (например, `topics: [JavaScript, Web]`).
  - **Локальные теги**: указываются прямо в карточке (например, `%% @card #async #сложно topic:: Frontend %%`).
  - Все атрибуты объединяются в единый набор без дубликатов.
- 🎨 **Нативный рендеринг Obsidian API**: отрисовка через `MarkdownRenderer.render` с корректной выгрузкой компонентов и защитой от утечек памяти.
- 🧭 **Интерактивный интерфейс изучения (Study View)**:
  - Индикатор статуса карточки (`ИНФО`, `КАРТОЧКА`, `Новая карта` / `Интервал: X дн.`).
  - Фильтрация по файлам, папкам и кликабельным тегам-чипсам с живым поиском.
  - Кнопка перемешивания колоды (Shuffle).
  - Быстрый переход к исходнику в заметке с позиционированием курсора на нужной строке.
  - Два режима показа ответа: отображение ответа под вопросом через разделитель либо замена вопроса ответом при перевороте.
- ⌨️ **Горячие клавиши**:
  - `Space` — показать ответ / перейти к следующей карте.
  - `1`, `2`, `3`, `4` — выбор оценки (Снова, Трудно, Хорошо, Легко) в режиме «Проверить знания».
  - `ArrowLeft` / `ArrowRight` — навигация по карточкам.
  - `Ctrl+Z` / `Cmd+Z` — отмена последнего действия.

## Синтаксис разметки

### 1. Подготовка заметки (Frontmatter)

Чтобы файл обрабатывался плагином, добавьте управляющий тег в свойства:

```yaml
---
tags:
  - seelearn
topics:
  - Компьютерные сети
---
```

### 2. Разметка карточки

#### Двусторонняя карточка (вопрос и ответ):
```markdown
%% @card #tcp #handshake %%
%% @front %%
Как происходит трехстороннее рукопожатие (Three-way handshake) в TCP?
%% @back %%
1. Клиент отправляет **SYN** (Synchronize).
2. Сервер отвечает **SYN-ACK**.
3. Клиент отправляет **ACK** (Acknowledge).

После этого соединение считается установленным.
%% @end %%
```

#### Односторонняя карточка (Инфо / Памятка):
Блок `@back` можно не указывать, если это информационный фрагмент для режима «Ботать»:
```markdown
%% @card #golang #concurrency %%
%% @front %%
> [!TIP] Go Channels
> Каналы в Go по умолчанию небуферизованные (`make(chan int)`), что означает блокировку отправителя до момента, пока получатель не прочитает значение.
%% @end %%
```

#### Альтернативный синтаксис (без `%%`):
```markdown
@card #алгоритмы #сложность
@front
Какова средняя временная сложность быстрой сортировки (QuickSort)?
@back
Средняя сложность: $O(n \log n)$
Худшая сложность: $O(n^2)$
@end
```

### 3. Правила валидации:
- У каждой карточки должен быть строго **один** блок `@front`.
- Блок `@back` опционален (при его отсутствии карточка помечается бейджем `ИНФО`).
- Порядок блоков `@front` и `@back` внутри карточки может быть любым. При изучении всегда первым показывается `@front`.
- Если блок `@front` отсутствует или дублируется, плагин выводит предупреждение и пропускает невалидную карточку.

## Установка и сборка

1. Установите зависимости:
```bash
npm install
```

2. Запуск тестов:
```bash
npm test
```

3. Сборка для публикации:
```bash
npm run build
```

Файлы `main.js`, `manifest.json` и `styles.css` помещаются в папку плагина в вашем хранилище:
`<Vault>/.obsidian/plugins/seelearn/`
