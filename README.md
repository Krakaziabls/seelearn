# SeeLearn — Интерактивные флеш-карты для Obsidian

[![Release](https://img.shields.io/github/v/release/Krakaziabls/seelearn?color=7c3aed&label=Release)](https://github.com/Krakaziabls/seelearn/releases)
[![Obsidian](https://img.shields.io/badge/Obsidian-v1.0.0+-blue?logo=obsidian)](https://obsidian.md)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Tests](https://img.shields.io/badge/Tests-65%20passed-brightgreen.svg)]()

**SeeLearn** — это плагин для [Obsidian](https://obsidian.md), который превращает размеченные фрагменты ваших заметок в интерактивные карточки для запоминания и интервального повторения по научно обоснованному алгоритму **SuperMemo-2 (SM-2)**.

Главный принцип плагина — **Zero Note Pollution (ноль мусора в заметках)**: карточки органично вписываются в ваши конспекты, скрываются в режиме чтения через комментарии, а весь прогресс, счетчики повторений, интервалы и забывания сохраняются исключительно во внутреннем хранилище плагина (`data.json`), никогда не изменяя ваши Markdown-файлы.

---

## 🚀 Быстрый старт (First-Run Experience)

SeeLearn готов к работе сразу после установки без сложной ручной настройки:

1. **Автоматический онбординг**: При первом запуске плагин автоматически создает в корне вашего хранилища изолированную папку **`SeeLearn Examples`** с 5 эталонными заметками и двумя интерактивными шпаргалками (по синтаксису и по методологии).
2. **Встроенная интерактивная шпаргалка**: В левом углу панели навигации плагина доступна постоянная кнопка справки **`(?)`**, которая в один клик открывает шпаргалку по синтаксису и разворачивает папку `SeeLearn Examples` в проводнике файлов Obsidian.
3. **Открытие плагина**: Нажмите на иконку карточек на левой боковой панели Obsidian или вызовите команду `SeeLearn: Открыть панель изучения карточек (Study View)`. Вы сразу увидите готовые карточки из папки примеров!

## 📦 Что внутри папки `SeeLearn Examples`?

В состав онбординга входят 5 полноценных заметок с примерами и 2 емкие интерактивные шпаргалки:

| Файл | Описание и возможности |
|---|---|
| **`01 — Базовые двусторонние карточки.md`** | Классические карточки вопрос-ответ (`@front` / `@back`), обратный порядок секций, плавная прокрутка длинного контекста. |
| **`02 — Карточки с пропусками (Cloze Deletions).md`** | Синтаксис Anki `{{c1::ответ}}`, `{{c1::ответ::подсказка}}`, подсветка `==ответ==`, множественные пропуски $c1, c2$ и объединение пропусков с секцией `@back`. |
| **`03 — Карточки с кодом и программированием.md`** | Блоки кода с нативной подсветкой синтаксиса (TypeScript, Python, Rust, SQL), форматирование структур данных и алгоритмов. |
| **`04 — Формулы LaTeX и точные науки.md`** | Рендеринг формул через MathJax, inline-математика `$E=mc^2$`, блочные уравнения `$$...$$`, дроби, интегралы и матрицы. |
| **`05 — Конспект лекции со скрытыми картами.md`** | Пример реального конспекта: карточки спрятаны в многострочные комментарии `%%%% ... %%%%` и **полностью невидимы** в режиме чтения Obsidian (Reading View). |
| **`Шпаргалка SeeLearn — Синтаксис.md`** | Емкий, наглядный справочник по созданию карточек, тегам, размерам и горячим клавишам без лишнего шума. |
| **`Шпаргалка SeeLearn — Методология.md`** | Практическое руководство по эффективному обучению: 2 режима, компас 4 кнопок оценок, защита от перегрузок и борьба с «пиявками». |

## ✨ Ключевые возможности

### 🧠 Умное интервальное повторение (SuperMemo-2 / SM-2)
- **4 градации оценки**: `[1] Снова` (сброс интервала, повтор сегодня), `[2] Трудно`, `[3] Хорошо`, `[4] Легко` (бонус к интервалу).
- **Динамический расчет интервалов**: расчет коэффициента легкости ($EF \ge 1.3$) и живой прогноз следующего срока повторения прямо на кнопках до нажатия.
- **Очереди обучения**: фильтрация по статусам **«К повторению»** (Due — созревшие на сегодня карточки), **«Новые»** (New) и **«Все»** (All).

### 🔄 Два переключаемых режима
- **«📖 Ботать»**: свободный просмотр и изучение карточек в своем темпе без выставления оценок.
- **«🎯 Проверить знания»**: режим интервального тестирования по алгоритму SM-2 с выставлением оценок и учетом прогресса.

### 🛡️ Zero Note Pollution (Бережное отношение к заметкам)
- Плагин никогда не дописывает в ваши заметки служебные ID, метаданные или даты повторений.
- Стабильный 64-битный хэш (FNV-1a) идентифицирует карточку по её содержанию. Даже если вы переместите карточку в другой файл или измените окружающий текст конспекта, прогресс сохранится.

### 📐 Гибкая система размеров карточек (Card Sizing & Presets)
- **Дискретная шкала**: `xs` (480px), `s` (560px), `m` (640px, стандарт по умолчанию, гармонирует с лобби), `l` (800px), `xl` (960px) и `full` (на весь экран).
- **Декларативное управление**:
  - Индивидуально для карточки: `%% @card #тема @size:xl %%`.
  - Для всей заметки через YAML frontmatter: `card_size: l` (имя свойства настраивается).
- **Интерактивное масштабирование в сессии**:
  - Кнопка разворачивания во весь экран (`maximize-2` / `minimize-2`) в шапке карточки.
  - Угловой хэндл в правом нижнем углу для плавного ресайза мышью или тачем со снапом к пресетам.
- **Умное сохранение без загрязнения заметок**: изменения размера в сессии автоматически запоминаются в `data.json` для карт без явного `@size:` и свойства в файле. В настройках доступна кнопка сброса всех сохраненных размеров к дефолту.

### 🙈 Полное скрытие карточек в конспекте (`%%%%`)
- Оборачивайте карточки в блоки `%%%% ... %%%%`, чтобы они оставались доступными для плагина, но были **абсолютно невидимы в режиме чтения Obsidian (Reading View)** и не отвлекали при изучении конспекта.

### ⚡ Детектор трудных карточек («Пиявки» / Leeches)
- Карточки, на которых вы часто ошибаетесь ($\ge 4$ нажатий «Снова»), автоматически помечаются бейджем `⚡ Пиявка`.
- Предупреждающий баннер в лобби позволяет запустить отдельную целевую сессию для проработки проблемных мест.

### 📦 Сохраненные наборы тестов (Test Presets)
- Сохраняйте текущую выборку (папку, заметку, фильтры по темам) в именованный тест («Сохранить как тест...»).
- Запускайте сохраненные тесты в 1 клик прямо из Лобби сессии с персональной статистикой запусков.

### 📱 Свайп-навигация для смартфонов (Obsidian Mobile)
- Нативные touch-жесты для быстрого повторения карточек на смартфонах и планшетах:
  - **Свайп вверх**: показать ответ (перевернуть карточку).
  - **Свайп влево**: следующая карточка / оценка «Снова» (Again).
  - **Свайп вправо**: предыдущая карточка / оценка «Хорошо» (Good).
- Защита от случайных срабатываний при горизонтальном скролле таблиц и блоков кода.

### 🎯 Настраиваемый лимит карточек и ранний выход
- Интерактивный счетчик в тулбаре (`Кол-во карт: N ▾`) позволяет выбрать или ввести любое число карточек на сессию, а также зафиксировать лимит в настройках плагина.
- Кнопка выхода в навигационной панели (`log-out`) позволяет в любой момент завершить активную сессию («Ботать» или «Проверка знаний») с гарантированным сохранением всего наработанного прогресса.
- Кнопка быстрого перехода в шапке карточки с нативным быстрым тултипом мгновенно открывает исходную заметку на нужной строке.

### 📊 Аналитика и мотивация
- **35-дневный календарь активности (Activity Heatmap)** с градиентной визуализацией интенсивности повторений.
- **Трекинг серий (Study Streaks)**: учет текущей непрерывной серии дней (`🔥 Стрик`) и личного рекорда (`🏆 Рекорд`).

### 🔀 Честное перемешивание и чередование тем (Interleaving)
- Алгоритм Фишера-Йетса для случайного тасования очереди.
- Опция **Topic Interleaving** предотвращает скопление карточек одной темы подряд.

## 📝 Синтаксис разметки

### 1. Подключение заметки к плагину

Добавьте управляющий тег `seelearn` в свойства заметки (YAML Frontmatter):

```yaml
---
tags:
  - seelearn
topics:
  - Архитектура
  - Сети
---
```

> Все темы из свойства `topics` автоматически наследуются всеми карточками внутри этой заметки.

---

### 2. Примеры карточек

#### Вариант A. Карточка в комментариях (рекомендуемый, скрыто в Reading View):
```markdown
%% @card #tcp #handshake %%
%% @front %%
Как происходит трехстороннее рукопожатие (Three-way handshake) в протоколе TCP?
%% @back %%
1. Клиент отправляет **SYN** (Synchronize).
2. Сервер отвечает **SYN-ACK**.
3. Клиент отправляет **ACK** (Acknowledge).

После этого соединение переходит в статус `ESTABLISHED`.
%% @end %%
```

#### Вариант B. Карточка с пропусками (Cloze Deletions):
Для карточек с пропусками маркеры `@front` и `@back` указывать **не обязательно**:
```markdown
%% @card #история %%
Столица Франции — {{c1::Париж::город}}, а основана она была в {{c2::III веке до н. э.}}.
%% @end %%
```
*Карточка автоматически разделится на две: в $c1$ будет скрыт Париж (с подсказкой `[город]`), а в $c2$ — век основания.*

Также поддерживается нативное выделение Obsidian:
```markdown
%% @card %%
Основным переносчиком энергии в клетке является ==молекула АТФ==.
%% @end %%
```

#### Вариант C. Полное скрытие в конспекте через `%%%%`:
```markdown
%%%%
@card #биология #цитология
@front
Какова функция рибосом в живой клетке?
@back
Биосинтез белка на основе генетической информации из мРНК.
@end
%%%%
```

#### Вариант D. Открытый синтаксис (без знаков `%`):
```markdown
@card id::quicksort-complexity #алгоритмы
@front
Какова средняя и худшая временная сложность быстрой сортировки (QuickSort)?
@back
- В среднем: $O(n \log n)$
- В худшем случае: $O(n^2)$ (при неудачном выборе опорного элемента)
@end
```

## ⌨️ Горячие клавиши и управление

### Во время учебной сессии

| Клавиша | Действие |
|---|---|
| `Space` | Показать ответ (перевернуть карточку) / Перейти к следующей |
| `1` или `Num1` | Оценка **«Снова»** (Again) в режиме теста |
| `2` или `Num2` | Оценка **«Трудно»** (Hard) в режиме теста |
| `3` или `Num3` | Оценка **«Хорошо»** (Good) в режиме теста |
| `4` или `Num4` | Оценка **«Легко»** (Easy) в режиме теста |
| `ArrowLeft` / `ArrowRight` | Предыдущая / Следующая карточка |
| `Ctrl+Z` / `Cmd+Z` | **Отмена (Undo)** последнего действия с восстановлением очереди |

### Команды командной палитры Obsidian (`Ctrl+P` / `Cmd+P`)

- `SeeLearn: Открыть панель изучения карточек (Study View)`
- `SeeLearn: Вставить шаблон карточки (Insert Card Template)`
- `SeeLearn: Вставить шаблон карточки с пропуском (Insert Cloze Template)`
- `SeeLearn: Перемешать карточки в текущей сессии (Shuffle Queue)`
- `SeeLearn: Показать ответ / Перевернуть карточку (Flip Card)`
- `SeeLearn: Оценка SRS: [1] Снова / [2] Трудно / [3] Хорошо / [4] Легко`

## 📥 Установка

### Способ 1. Через плагин BRAT (Рекомендуемый для бета-тестирования)

1. Установите плагин **BRAT** (Beta Reviewers Auto-update Tester) из официального каталога сообщества Obsidian.
2. В настройках BRAT нажмите **Add Beta plugin**.
3. Вставьте ссылку на репозиторий: `https://github.com/Krakaziabls/seelearn`
4. Нажмите **Add Plugin** — BRAT автоматически скачает актуальный релиз и будет обновлять его при выходе новых версий.
5. Включите **SeeLearn** в разделе *Настройки -> Сторонние плагины*.

### Способ 2. Ручная установка из GitHub Releases

1. Перейдите на страницу [GitHub Releases](https://github.com/Krakaziabls/seelearn/releases) и откройте последний релиз.
2. Скачайте три файла: `main.js`, `manifest.json`, `styles.css`.
3. В вашем хранилище Obsidian откройте каталог:
   `<Хранилище>/.obsidian/plugins/seelearn/` (если папки `seelearn` нет, создайте её).
4. Скопируйте скачанные файлы в эту папку.
5. Перезагрузите Obsidian или нажмите кнопку обновления списка плагинов и активируйте **SeeLearn**.

```bash
# Клонирование репозитория
git clone https://github.com/Krakaziabls/seelearn.git
cd seelearn

# Установка зависимостей
npm install

# Запуск тестов и статической проверки типов
npm run verify

# Сборка плагина для продакшена
npm run build
```
