# UI & Styling Constraints

1. **Только нативные CSS-переменные Obsidian:**
   - Категорически запрещено использовать захардкоженные HEX/RGB цвета для фонов, текста, границ и кнопок.
   - Используй стандартную дизайн-систему Obsidian:
     * Фон окна / карточки: `var(--background-primary)`
     * Вторичный фон / сайдбар / панели: `var(--background-secondary)`
     * Границы и разделители: `var(--background-modifier-border)`
     * Основной текст: `var(--text-normal)`
     * Вспомогательный текст / хинты: `var(--text-muted)`
     * Ошибки / пиявки / опасные действия: `var(--text-error)` / `var(--background-modifier-error)`
     * Успех / легкие карточки: `var(--text-success)` / `var(--background-modifier-success)`
     * Акцентные элементы и кнопки: `var(--interactive-accent)` (текст: `var(--text-on-accent)`)
     * Скругления: `var(--radius-s)`, `var(--radius-m)`, `var(--radius-l)`

2. **Изоляция и скоупинг классов:**
   - Все CSS-классы плагина обязаны начинаться с префикса `.seelearn-` (например, `.seelearn-card-area`, `.seelearn-progress-pill`, `.seelearn-btn-primary`).
   - Не переопределяй глобальные селекторы Obsidian (`button`, `.workspace-leaf`, `h1`) без селектора плагина-предка.

3. **Ограничения высоты карточки и вертикальный скролл:**
   - Область карточки `.seelearn-card-area` должна строго умещаться по высоте внутри вьюшки / контейнера.
   - Для карточек с длинным контекстом внутренний контейнер текста должен быть прокручиваемым (`overflow-y: auto`, `max-height: 100%`), чтобы элементы управления (кнопки оценок, стрелки навигации) оставались видимыми и не уезжали за экран.

4. **Ширина и выравнивание кнопок:**
   - Парные или групповые кнопки действий (например, «Ботать» и «Проверка знаний») должны иметь одинаковую ширину (`flex: 1 1 0` или фиксированный `min-width`) для сохранения визуального баланса.

5. **Иконки:**
   - Не используй эмодзи для системных кнопок интерфейса.
   - Используй нативные SVG-иконки Lucide через метод Obsidian API `setIcon(el, 'icon-name')`.
