---
description: Автоматическая инспекция и тестирование интерфейса плагина через Chrome DevTools MCP
---

1. Проверь статус отладочного порта Obsidian:
   ```bash
   curl -s http://127.0.0.1:9222/json || echo "Port 9222 closed"
   ```
   - Если порт 9222 открыт: подключись к рантайму Obsidian через Chrome DevTools MCP (`--browserUrl http://127.0.0.1:9222`).
   - Если порт 9222 закрыт: используй автономный браузер Chrome через инструмент `navigate_page` или CLI `chrome-devtools`.

2. Выполни инспекцию DOM-дерева (`take_snapshot`):
   - Проверь наличие ключевых контейнеров: `.seelearn-study-container`, `.seelearn-card-area`, `.seelearn-card-body`.
   - Проверь бейджи карточки:
     * Для пиявок: присутствует класс `.is-leech`, отсутствует `.is-new`.
     * Для cloze-карточек: пилюля содержит только лаконичный символ.

3. Проверь стили и геометрию элементов (`get_css_styles`):
   - Проверь ширину кнопок в лобби: кнопки запуска сессии должны иметь равную ширину (`flex: 1 1 0` или идентичный `computed width`).
   - Проверь ограничение высоты: `.seelearn-card-area` не должна переполнять родительский вьюпорт; внутренний контент должен иметь `overflow-y: auto`.

4. Сними скриншот (`take_screenshot`):
   - Сохрани скриншот в `scratch/ui-test.png` для визуального подтверждения соответствия требованиям.

5. Проверь ошибки в консоли (`list_console_messages`):
   - Убедись, что нет необработанных исключений и сообщений уровня `error`.
