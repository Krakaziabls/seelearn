---

1. Проверь типизацию TypeScript:
   ```bash
   npx tsc --noEmit -skipLibCheck
   ```
   Убедись, что нет ошибок несоответствия типов с `obsidian.d.ts`.

2. Запусти полный набор автоматических unit-тестов бизнес-логики:
   ```bash
   bash -c 'source ~/.nvm/nvm.sh && nvm use 20 && npm test'
   ```
   Убедись, что все тесты (парсер, SM-2, cloze, хранилище, хэширование) проходят со 100% успехом (0 fail).

3. Проверь сборку продакшен-бандла плагина:
   ```bash
   bash -c 'source ~/.nvm/nvm.sh && nvm use 20 && npm run build'
   ```
   Убедись, что `main.js` сформирован без предупреждений и ошибок сборщика esbuild.

4. Проверь состояние спецификаций OpenSpec:
   ```bash
   openspec doctor --json
   ```
   Убедись, что `healthy: true` и список замечаний пуст.

5. Сформируй краткий структурированный отчет о результатах верификации.
